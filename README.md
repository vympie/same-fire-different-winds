# Same Fire, Different Winds

A cinematic, responsive website exploring heroes, villains, human instincts, and the choices that separate protection from harm.

## Pages
- **Home** — introduces the central idea and links to every section.
- **Heroes** — character cards and reflections on responsibility, courage, and imperfect choices.
- **Villains** — character cards exploring motives without excusing harm.
- **Human** — explores instinct, family, loyalty, the common good, and a Harry Dresden example from *The Dresden Files*.
- **The Harsh Truth** — the central quote and the moral grey area between personal loyalty and wider responsibility.

## Run it
Open index.html in a browser, or publish the repository with GitHub Pages.

Character thumbnails are requested from the Wikipedia REST summary API when a page loads. If a thumbnail is unavailable, the card displays initials instead. Google Fonts are used for typography.

Character names and franchises belong to their respective owners.
