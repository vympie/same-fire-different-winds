# Same Fire, Different Winds

A small, cinematic website about heroes, villains, and the choices that separate them.

## Pages
- **Home** — introduces the idea and links to each section.
- **Heroes** — character cards with short descriptions.
- **Villains** — character cards exploring motives without excusing harm.
- **The Harsh Truth** — the central quote and a reflection on the grey area between right and wrong.

## Run it
This is a static website. Open `index.html` in a browser, or use GitHub Pages to publish the repository.

Character thumbnails are requested from the Wikipedia REST summary API when a page loads. If a thumbnail is unavailable, the card displays initials instead. Google Fonts are used for typography.

Character names and franchises belong to their respective owners.
